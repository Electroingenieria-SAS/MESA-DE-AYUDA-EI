# Mesa de Ayuda EI

Plataforma institucional para la radicación, gestión, seguimiento y consulta de solicitudes de Calidad y Mejoramiento Continuo de Electroingeniería S.A.S.

## Funcionalidad

Permite registrar solicitudes, consultar radicados, gestionar responsables, prioridades, estados, tiempos de atención, evidencias y comunicaciones asociadas al servicio.

## Componentes

La solución está conformada por un portal de solicitudes, un panel interno de gestión, herramientas de seguimiento y trazabilidad, asistencia para orientación y redacción, recursos multimedia y servicios de datos para la operación.
